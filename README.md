# Interval Timer

**Open the app: https://zmaciej.github.io/IntervalTimer/**

A simple full-screen interval timer that works in any browser, on desktop and phone.

## How to use

1. **Add stages.** Give each stage a name, a time and a color.
2. **Group stages** to repeat them. Add a group, set how many times it should run and drag stages into it.
3. **Reorder** stages and groups by dragging the handle on the left.
4. Press **Start**. The timer runs through all stages one after another.

## Entering time

Just type digits and the time formats itself:

- `50` → 50 seconds
- `500` → 5:00
- `50000` → 5:00:00

## While the timer runs

- The screen shows the stage name, the remaining time and your position in the plan.
- The background takes the color of the current stage.
- A thin bar at the top shows the progress of the whole plan.
- Use the play/pause button to pause and resume, and the stop button to go back to the settings.
- The screen stays on while the timer is running.

Your plan is saved in the browser, so it will be there next time you open the app.

## Sharing a plan

The plan is stored in the page address (everything after the `?`) and updates as you edit. Copy the link to save or share it, or bookmark it. Opening such a link loads that plan.
